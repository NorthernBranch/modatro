# Third-party content and removal policy

Modatro is an independent community mod catalogue and installer for Balatro. It is
not affiliated with, endorsed by, or sponsored by LocalThunk or Playstack.

## Ownership and distribution

Mod authors retain ownership of their mods. Modatro does not claim ownership or
require a copyright transfer. Downloads normally go directly from the author's
repository or release source to the user's computer. Modatro does not host copies
of mod archives. A different distribution source requires recorded author approval;
automatic downloads currently support the documented HTTPS GitHub hosts only.

An entry's display, installation and update permissions are separate. Inclusion in
the archived Balatro Mod Index is labelled **Legacy index**, and does not establish
explicit Modatro approval. **Author approved** means approval for catalogue inclusion,
not a guarantee about code security. Licence metadata is informational; Modatro does
not automatically decide whether a licence permits a particular use.

Descriptions must be author-supplied, appropriately licensed, or short factual text
written for the index. Modatro does not scrape or reproduce full READMEs. Artwork
requires explicit catalogue display permission or an appropriate licence and recorded
evidence. Current cards use Modatro's own neutral icons, including when no approved
artwork exists. Official Balatro artwork or logos are not used as Modatro's brand.

## Removal requests and copyright complaints

Authors and rights holders can use [Request removal](https://github.com/NorthernBranch/modatro/issues/new?template=removal.yml).
Provide the mod ID, source repository and evidence that you control the project or
the affected rights, such as the matching repository owner account or a confirmation
in the upstream project. A reason is optional. Copyright complaints may identify
the specific text or image and the original work. Do not include private credentials.

Maintainers verify control and record a removal in the independent revocation feed.
Authors do not need to justify their decision. Verified removal prevents future
Modatro installations and updates, including from saved catalogues. It does not
remotely delete, disable or modify existing user copies. Users can continue local
management and explicitly uninstall files they have chosen to place under Modatro's
management.

## Release restrictions

Maintainers can block an entire source or a particular broken or potentially
compromised release. Existing installations remain untouched and show the restriction.
A safe newer release can still be offered when only an older version is blocked.
Restrictions are checked independently of the full catalogue and take precedence
over cached entries. When current checks cannot finish, catalogue browsing and local
operations remain available, while new downloads and updates pause.

Mods are third-party software. Modatro checks installation metadata, paths and file
integrity where possible. It does not comprehensively scan mod code or guarantee that
mods are free of bugs or malicious code. A changed archive for the same recorded
release stops automation; it does not by itself prove malicious behavior.
